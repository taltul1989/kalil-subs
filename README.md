# קליל כתוביות

אתר שמוסיף כתוביות לסרטונים בעברית.

- התמלול רץ בדפדפן, על כרטיס המסך של המכשיר, עם מודל העברית של [ivrit.ai](https://huggingface.co/ivrit-ai) (גרסת ONNX של whisper-large-v3-turbo).
- הסרטון לא עולה לשום שרת.
- אפשר לערוך את הכתוביות ולהוריד את הסרטון עם הכתוביות צרובות, או קובץ SRT / VTT / טקסט.

## הרצה מקומית

```
node server.js
```

ואז לפתוח http://localhost:5179
